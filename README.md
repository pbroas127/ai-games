# AI Arcade

A growing collection of small browser games built with AI. No build steps, no
dependencies — every game is a self-contained folder you can open directly.

## Play

- **Online**: https://pbroas127.github.io/ai-games/ (GitHub Pages)
- **Local**: clone and double-click any game's `index.html`

## Games

| Game | Folder | What it is |
| --- | --- | --- |
| Feather Dash | [`feather-dash/`](feather-dash/) | Voxel endless road-crosser — cars, logs, trains, one determined chicken |
| Off the Map | [`geo-sports-trivia/`](geo-sports-trivia/) | Sports trivia answered by clicking a world map — points scale with how close you got |
| Bait | [`bait/`](bait/) | Build a room that looks fair and isn't, prove it by clearing it, share it as a code that *is* the room |

## Adding a game

1. Make a new folder with a self-contained `index.html` (vendor any libraries
   into the folder so it works offline and on Pages).
2. Add a card for it in the root `index.html` launcher.
3. Add a row to the table above, commit, push.
